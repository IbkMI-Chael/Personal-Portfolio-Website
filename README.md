# Michael Arebisola — Video Editing Portfolio

A personal portfolio website showcasing my services, projects, and journey as a video editor.

## About the Project

This website was created as a personal portfolio for **Michael Arebisola**, a video editor focused on transforming raw footage into engaging and visually refined videos.

The portfolio gives potential clients a simple way to learn about my services, explore my projects, and get in contact with me.

## Features

* Personal introduction and professional identity
* Video editing services section
* Project showcase page
* About Me section
* Direct email contact button
* Instagram profile information
* Hover effects and interactive visual elements
* Responsive viewport configuration

The portfolio currently highlights the following services:

## Design

The website uses a dark blue color palette with light text and subtle transparent elements to create a clean and modern portfolio aesthetic.

Hover effects are also used throughout the website to make interactive elements more noticeable while maintaining a minimal visual style.

## Purpose

This project serves two purposes:

1. To create a professional online presence as a video editor.
2. To document my progress as I continue developing my video editing and web development skills.
